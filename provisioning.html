Test E Provisioning

api-test-tool を起動している PC の LAN IP を入力し、Android 端末ごとに A / B / C のボタンをタップしてください。

Android 実機では localhost / 127.0.0.1 を使用できません。PC の LAN IP と port 3200 を指定してください。 PC 上の Test E runner は IVR_E_WEB_API_BASE=http://127.0.0.1:3200 のままで構いません。

Test E 端末A（101 / webrtc_101）を設定 Test E 端末B（102 / webrtc_102）を設定 Test E 端末C（103 / webrtc_103）を設定
